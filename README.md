# BIOPHLO — React Frontend

Responsive, frontend-only implementation of the BIOPHLO biology-learning landing page.

## Stack

- React 19
- TypeScript
- Vinext / Vite
- Tailwind CSS
- Lucide React icons

## Included

- Responsive desktop, tablet, and mobile layouts
- BIOPHLO hero and navigation
- Learning-benefit cards
- Four-step hexagonal learning journey
- Instructor section and statistics
- Biology course cards
- Interactive video/quiz lesson section
- Benefits, CTA, and footer
- Reduced-motion accessibility support

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Production build

```bash
npm run build
npm start
```

## Main files

- `app/page.tsx` — page structure and interactions
- `app/globals.css` — complete styling and responsive layouts
- `app/layout.tsx` — metadata and root layout
- `public/assets/` — image and brand assets

This package contains source files only. Dependencies and generated build folders are intentionally excluded.
